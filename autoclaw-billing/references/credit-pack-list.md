# 查询积分加油包

用于查看 AutoClaw/智谱积分加油包、积分包、点数包、额度包或充值档位。

注意：“积分怎么买/怎么买积分/都可以怎么买积分/积分怎么充值/有哪些购买方式”是获取方式咨询，应先使用获取方式模板同时说明月度会员套餐和积分加油包，不要只展示加油包。

## 流程

1. 运行：
   ```bash
   <PY> "scripts/autoclaw_pay_cli.py" product-info
   ```
2. 只读取 `boost_list`，不要读取 `member_list`。
3. 输出前读取选定语言模板的加油包列表模板。

## 展示规则

- 列表为空：说明当前未返回积分加油包，不编造档位。
- 展示名称、基础积分 `send_score_forever`、赠送 `send_activity_score`、价格、有效期 `period_day`、状态 `available`。
- 有效期缺失写“未返回”；赠送缺失或 0 写 `0` 或“无”。
- 除非用户只要求可购买加油包，否则展示所有返回条目及状态。
- 只有用户要求推荐时，才基于每积分单价、积分量、有效期给建议。
