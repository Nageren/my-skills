# i18n 语言选择

本文件只负责语言选择和模板加载路径，不存放完整回复模板。

## 语言判定

| 场景 | 输出语言 |
|---|---|
| 用户明确说“用中文/中文回复” | 中文 |
| 用户明确说“in English / English please” | English |
| 用户主要用中文提出业务请求 | 中文 |
| 用户主要用英文提出业务请求 | English |
| 用户中英混合但动作词是中文，例如“帮我 buy Pro 月度会员” | 中文 |
| 无法判断 | 中文 |

API 字段名、商品 ID、endpoint、状态值、货币代码不翻译。用户可见说明、表头、确认文案、错误解释和下一步动作必须使用选定语言。

## 模板加载

| 输出语言 | 模板文件 | 加载时机 |
|---|---|---|
| 中文 | `templates/zh-CN.md` | 需要列表、确认、缺少数据源、订单结果或状态文案时 |
| English | `templates/en-US.md` | 需要列表、确认、缺少数据源、订单结果或状态文案时 |

只加载一个语言模板。不要同时加载中英文模板，除非用户明确要求双语输出。
